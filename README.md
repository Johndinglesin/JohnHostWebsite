# JohnHost

JohnHost is a small, free host for Minecraft servers and websites. We run both on borrowed hardware so people can play and publish without paying.

Each Minecraft server gets 1 core, 6 GB RAM, 64 GB storage, 2 backups, and 1 port. Each website gets 5 GB SSD, 50% CPU, and 1.5 GB RAM over HTTPS.

The website is coded in HTML, JavaScript, and CSS.
